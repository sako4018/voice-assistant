# Voice Assistant — Jarvis

Гласов асистент за Windows. Държиш **десен Ctrl**, казваш какво искаш на английски,
пускаш клавиша — и той го прави. Никакви фиксирани фрази: "play some music", "lock
the computer", "search the weather" работят, без да са записани никъде в кода.

Командите са на английски, защото Whisper е чувствително по-точен на английски
отколкото на български, особено на малкия модел, който Jarvis ползва за скорост.

По-старите версии бяха на събуждаща дума ("hey jarvis") и в реална употреба не
сработиха нито веднъж. Всички реално ползвани проекти от този тип (whisper-writer,
VoiceInk, whisper-hotkey) са на клавиш — затова и тази версия е.

## Изисквания

Всичко върви с **Python 3.13** (`py -3.13`). Python 3.14 не компилира PyAudio-related
пакети на тази машина.

```
py -3.13 -m pip install faster-whisper sounddevice pynput pyttsx3 soxr ^
    pyautogui pyperclip pystray Pillow numpy requests
```

Мозъкът е [OmniRoute](https://www.npmjs.com/package/omniroute) на `localhost:20128`.
Jarvis го пуска сам, ако не върви (студен старт ~75 сек).

## Пускане

```
py -3.13 jarvis.py
```

Три тона = готов. Държиш **десен Ctrl**, говориш, пускаш клавиша.

Рамката на екрана светва, докато говориш, после показва какво е чуто и какво е
направено за няколко секунди — винаги виждаш какво се е случило, дори да сгреши.

Иконата до часовника: десен бутон →

- **Провери** — микрофон, Whisper, OmniRoute, всичко на ред
- **Покажи лога** — `jarvis.log` в Notepad
- **Настройки (config.json)** — отваря файла
- **Рестартирай** — пуска нов процес с последния код и излиза от текущия
- **Изход**

## Настройки (`config.json`)

Копирай `config.example.json` на `config.json` и променяй по желание:

| ключ | какво прави |
|---|---|
| `hotkey` | клавишът за говорене, по подразбиране `ctrl_r` (десен Ctrl) |
| `language` | езикът, на който говориш командите (`en` по подразбиране) |
| `whisper_model` | `tiny`/`base`/`small`/`medium`/`large-v3` — по-голям = по-точен, по-бавен |
| `whisper_device` | `auto`/`cuda`/`cpu` — `auto` пробва видеокартата, при проблем пада на процесора сам |
| `input_device` | име на микрофон, `null` = каквото Windows води по подразбиране в момента |
| `speak_replies` | дали Jarvis да отговаря и на глас (не само на екрана) |
| `tts_voice` | име на Windows SAPI глас (`David`/`Zira` на тази машина) |

Ако разпознаването бърка думи — смени `whisper_model` на `medium` в `config.json`
(по-точен е, но отговаря за ~5 сек вместо ~2).

## Какво разбира

| казваш | прави |
|---|---|
| open youtube / open my email | отваря сайт |
| open notepad / open spotify | пуска програма |
| search for … / look up … | търси в Google |
| find … video on youtube | търси в YouTube |
| type … | пише го където е курсорът |
| play/pause/next song, turn it up/down | медийни клавиши |
| lock the computer | заключва |
| put the pc to sleep | приспива |
| shut down / restart | изключва (20 сек за отказ — кажи "cancel") |
| close chrome | затваря програма |
| what is 17 times 23 | просто отговаря |

Опасни команди (`format c:`, `del /s`, `diskpart` …) се отказват, дори моделът да ги
предложи — разпознаването може да сбърка.

Мозъкът (`kr/claude-haiku-4.5` през OmniRoute) понякога "излиза от роля" и отговаря
като себе си вместо като Jarvis. Разпознава се по фиксирани фрази ("I'm Kiro...",
"I can't discuss that...") и се повтаря автоматично веднъж — почти винаги оправя
проблема. Заявката има и твърд краен срок, за да не увисва, ако мрежата се
запъне.

## Ако не работи

```
py -3.13 jarvis.py --check
```

Показва в прозорче: микрофон намерен ли е, OmniRoute върви ли, Whisper зарежда ли
се, мозъкът отговаря ли. Може да се пуска, докато Jarvis върви.

Ако микрофонът мълчи — вероятно Windows слуша друго устройство по подразбиране
(напр. слушалки вместо вградения микрофон). Провери в Windows Settings → Sound,
или задай конкретно устройство в `config.json` с `input_device`.

## Автостарт

Копирай **двата** `.vbs` файла в `shell:startup`:

- `jarvis_autostart.vbs` — самият асистент, скрито, без конзола
- `omniroute_autostart.vbs` — мозъкът, паралелно с Jarvis (не е задължителен —
  Jarvis го вдига сам при нужда, но студеният старт е ~75 сек)

Пуска се само едно копие: ако Jarvis вече върви, второто излиза веднага.

Логът е в `jarvis.log` до скрипта (под `pythonw` няма конзола).

## Файлове

- `jarvis.py` — клавиш → запис → Whisper → мозък → действие → показва се на екрана
- `brain.py` — заявката към OmniRoute, системният промпт и разчитането на `[ACTION]`
- `actions.py` — какво Jarvis може да направи (`run_action`) и забранените команди
- `config.example.json` — образец за `config.json`
- `jarvis_autostart.vbs` / `omniroute_autostart.vbs` — стартиране с Windows
- `speech_to_texy.py` — простата база: микрофон → текст в терминала (не се пипа)
